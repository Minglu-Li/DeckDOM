# 05 — 就地编辑文字并保留内联结构

**What to build:** 用户可以在工作副本的真实渲染位置直接修改文字，同时尽量保留原有内联结构，并通过对象属性区调整整个文字对象的常用字体属性；每种修改都即时渲染，并能够撤销、恢复和导出。

**Blocked by:** 03 — 发现并层级选择可编辑对象.

**Status:** ready-for-agent

- [ ] 双击文字对象进入真实渲染位置上的直接编辑，退出编辑后形成一个用户意图级历史步骤。
- [ ] 修改普通文字不会无意移除已有的 `strong`、`span`、`code` 等内联语义结构。
- [ ] 从其他应用粘贴的内容按纯文本处理，不带入外部 HTML 和复杂样式。
- [ ] 用户明确选择替换全部文字时可以清除内部格式，但提交前必须看到影响提示并可以取消。
- [ ] 文字改变时浏览器按原 CSS 自然换行和重排，工作副本即时显示真实结果。
- [ ] 用户可以调整整个文字对象的字体族、字号、字重、字形、行高、字间距、对齐和文字颜色。
- [ ] 文字内容和字体属性修改只作用于当前对象，支持撤销、重做、浏览器本地恢复并正确进入 HTML 交付文件。
- [ ] 端到端测试覆盖普通文字、包含内联结构的文字、纯文本粘贴、替换全部文字提示和自然重排。
