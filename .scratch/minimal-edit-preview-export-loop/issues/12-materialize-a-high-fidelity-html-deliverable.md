# 12 — 固化高保真的 HTML 交付文件

**What to build:** 用户可以把当前工作副本导出为新的单文件 HTML 交付文件。所有首版内容与视觉修改在脱离 Web 编辑器后仍然生效，本地替换图片已经内嵌，原文档的结构、样式、脚本、动画和交互则尽量保持不变。

**Blocked by:** 05 — 就地编辑文字并保留内联结构; 06 — 本地替换图片并在导出时内嵌; 07 — 视觉移动与等比缩放对象; 08 — 应用对象级局部外观覆盖; 09 — 隔离编辑操作并恢复预览行为; 10 — 处理导入边界与资源诊断.

**Status:** resolved

- [x] 导出始终基于不可变原始 HTML 的副本创建新文件，不覆盖用户最初上传的文件。
- [x] 文字内容和图片内容等适合静态表达的修改写回带稳定编辑标识的对应对象。
- [x] 视觉位移、视觉缩放、字体和外观修改以局部导出补丁表达，不改写未选择对象的共享样式。
- [x] 本地替换图片内嵌在单个 HTML 文件中，不依赖用户计算机上的原文件路径。
- [x] 原始 CSS 与 JavaScript 主体尽量保持不变，原有链接、翻页、滚动和动画在独立打开时继续运行。
- [x] 导出文件保留稳定编辑标识，但不包含选框、手柄、工作台界面、编辑事件接管或其他编辑辅助内容。
- [x] 导出前工作副本和独立打开后的 HTML 交付文件在所有首版修改上保持一致。
- [x] 原文档已有外部资源和外部脚本继续保留原链接；首版不宣称自动打包为完全离线文件。

## Answer

导出现在始终重新解析不可变 `originalHtml`，在新的文档副本上按稳定编辑标识写回文字与图片，并将本地图片保持为内嵌 data URL。字体、外观、视觉位移和等比缩放统一生成对象级 `data-html-editor-export-patch`，不改写对象已有内联样式或共享 CSS；原 CSS、JavaScript、外部链接和稳定编辑标识继续保留，工作副本的 base、导入 token、模式标记、选框、手柄、事件接管和工作台 UI 不会进入交付文件。

新增真实 Chromium 交付 tracer：捕获下载到新文件，在独立页面打开，逐项对比综合文字、图片、字体、外观、位移与缩放的浏览器渲染，并验证原脚本、动画、外部资源链接以及 `test1.html` 的翻页/主题和 `test2.html` 的页内锚点/滚动。测试同时按字节确认原 fixture 未变化。验证通过：`npm run build`；`npm run test:e2e`（34 passed）；测试服务器端口为 4412。
