# 04 — 支持参考视口与长页面浏览

**What to build:** 用户可以在稳定的桌面参考视口中编辑 HTML 展示文档，并在不改变原文档形态的情况下浏览长滚动页面、切换桌面尺寸和调整工作台显示缩放；滚动或视口变化后，工作副本与编辑辅助界面仍准确对应。

**Blocked by:** 03 — 发现并层级选择可编辑对象.

**Status:** ready-for-agent

- [ ] 工作副本默认运行在 1440×900 的桌面参考视口，并在界面中明确显示当前宽高。
- [ ] 用户可以调整或选择其他桌面参考视口尺寸，原 HTML 的响应式 CSS 根据真实视口重新渲染。
- [ ] 参考视口变化不把长页面切成幻灯片，也不把翻页式文档转换成长滚动页面。
- [ ] 用户可以调整工作台显示缩放或使用适合画布功能，而不会改变 HTML 展示文档自身的布局尺寸。
- [ ] 编辑模式中滚轮和工作副本滚动条保持可用，用户可到达长页面当前视口之外的内容。
- [ ] 滚动、工作台缩放、参考视口变化和原页面可见状态变化后，当前选框重新同步到对象的实际渲染边界。
- [ ] 界面明确说明修改层只保证当前参考视口下的预期结果，不暗示跨所有断点自动适配。
- [ ] 长滚动验收样例可滚动到多个区块完成选择；翻页验收样例仍保持原有页面形态。
