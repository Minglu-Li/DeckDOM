# 14 — 改善容器选择、图片替换与页面交互

**What to build:** 修复外层容器选框阻塞内部对象的问题，在编辑模式提供可连续操作原页面的交互工具，并让图片替换可选择直接替换或非破坏性填充原图框。

**Status:** resolved

- [x] 外层容器被选中后，用户仍可直接点击其内部可编辑对象；仅拖动柄与缩放柄捕获指针。
- [x] 选择工具中点击画布空白或按 `Esc` 可取消当前选择，保存属性不会制造选择锁定。
- [x] 编辑模式提供选择工具与交互工具；交互工具允许原页面翻页、主题及键盘操作，`Esc` 返回选择工具且不重载工作副本。
- [x] 图片上传后默认选择直接替换，也可选择填充原图框；无有效原图框时明确禁用该选项。
- [x] 填充原图框与图片内容作为一次历史意图贯通撤销、重做、本地恢复和 HTML 导出。
- [x] 使用真实桌面 Chrome 覆盖用户报告的 `test1.html` / 容器场景和图片适配场景。

## Comments

- 2026-08-13: 用户确认交互方案；图片“裁切”正式收窄为 CSS `object-fit: cover` 的非破坏性图片填充框，不实现自由裁剪编辑器。

## Answer

选框本体改为不拦截指针，蓝色对象标签成为明确的移动柄，四角只负责等比缩放；因此选中 `section` 或最外层 `div` 后仍可直接点击内部对象。选择工具也支持画布空白与 `Esc` 清除选择，容器选框文案从“可编辑”收窄为“可调整”。

编辑模式新增“选择内容 / 操作页面”工具切换。“操作页面”在同一 iframe 工作副本中把点击与键盘交回原 HTML，真实 `test1.html` 可直接翻页与切主题；按 `Esc` 返回选择工具，页面状态不重载，工具切换不进入编辑历史。

图片文件验证后新增适配确认：默认直接替换并保留新图片比例；可选“填充原图框”，记录当前参考视口的原图框并用居中 `object-fit: cover` 非破坏性显示。图片内容和适配方式作为一次修改层意图贯通撤销、重做、本地恢复和独立 HTML 导出。`CONTEXT.md` 与 ADR 0037 固定了“图片填充框”术语和不修改图片像素的边界。

新增 5 条真实桌面 Chrome tracer，覆盖容器穿透/保存外观后继续选择、空白与 Esc 取消、`test1.html` 原页面交互、默认直接替换、键盘取消替换，以及填充原图框的历史/恢复/导出。`npm run build` 通过；完整桌面 Chrome E2E 48/48 通过；既有视觉基线无需更新。
