# 09 — 隔离编辑操作并恢复预览行为

**What to build:** 编辑模式为用户提供稳定、安全的对象操作环境，不因选择或快捷键误触原 HTML 的链接、按钮、翻页或动画；切换到预览模式后，同一工作副本完整恢复原页面交互和动画，供用户检查最终体验。

**Blocked by:** 03 — 发现并层级选择可编辑对象.

**Status:** resolved

- [x] 编辑模式中的普通点击由编辑辅助层接管，仅用于选择对象，不执行原 HTML 的链接、按钮或点击处理。
- [x] 编辑快捷键在编辑模式中优先于原页面快捷键，撤销、重做和选择操作不会被原脚本截获。
- [x] 编辑模式默认暂停 CSS 动画和过渡，以稳定对象位置和选框，且不改写原动画定义。
- [x] 进入预览模式后，选框、手柄、层级选择和对象属性编辑全部隐藏或停用，不成为渲染内容的一部分。
- [x] 预览模式恢复原页面的点击、键盘、滚动和 CSS 动画，并继续呈现修改层结果。
- [x] 从预览返回编辑模式时，修改、历史和项目状态不丢失，也不因模式切换产生额外历史步骤。
- [x] 翻页验收样例在编辑模式不会因选中对象误翻页或切换主题，在预览模式恢复其原操作。
- [x] 长滚动验收样例在预览模式恢复导航和锚点行为，返回编辑模式后可以继续选择当前可见对象。

## Answer

编辑模式现在在工作副本捕获普通点击和键盘事件：点击只用于对象选择，原链接、按钮、翻页和页面快捷键不执行；`Ctrl+Z`、`Ctrl+Y` 与 `Ctrl+Shift+Z` 优先驱动编辑历史。编辑辅助样式仅在编辑模式暂停 CSS animation 并把 transition 时长置零，不更改原动画名称或定义。

模式切换改为在同一个 iframe 工作副本上安装或移除编辑边界，不再重建文档，因此预览恢复原点击、键盘、滚动、页内锚点、动画与 transition，同时继续显示修改层；返回编辑保留页面运行状态、修改和历史，切换本身不新增历史。预览时层级面板、属性面板和选框隐藏并停用。工作副本加入仅编辑器运行时使用的 `about:srcdoc` base，避免页内锚点误导航到编辑器页面；该辅助标记不进入 HTML 交付文件。

新增真实 Chromium E2E 覆盖 `test1.html` 翻页/主题/页面快捷键、`test2.html` 修改层/编辑快捷键/锚点/滚动，以及 CSS animation 定义保留与播放状态切换。验证通过：`npm run build`；`npm run test:e2e`（26 passed）。测试服务器端口为 4409。
