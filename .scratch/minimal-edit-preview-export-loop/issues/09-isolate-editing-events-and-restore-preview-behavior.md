# 09 — 隔离编辑操作并恢复预览行为

**What to build:** 编辑模式为用户提供稳定、安全的对象操作环境，不因选择或快捷键误触原 HTML 的链接、按钮、翻页或动画；切换到预览模式后，同一工作副本完整恢复原页面交互和动画，供用户检查最终体验。

**Blocked by:** 03 — 发现并层级选择可编辑对象.

**Status:** ready-for-agent

- [ ] 编辑模式中的普通点击由编辑辅助层接管，仅用于选择对象，不执行原 HTML 的链接、按钮或点击处理。
- [ ] 编辑快捷键在编辑模式中优先于原页面快捷键，撤销、重做和选择操作不会被原脚本截获。
- [ ] 编辑模式默认暂停 CSS 动画和过渡，以稳定对象位置和选框，且不改写原动画定义。
- [ ] 进入预览模式后，选框、手柄、层级选择和对象属性编辑全部隐藏或停用，不成为渲染内容的一部分。
- [ ] 预览模式恢复原页面的点击、键盘、滚动和 CSS 动画，并继续呈现修改层结果。
- [ ] 从预览返回编辑模式时，修改、历史和项目状态不丢失，也不因模式切换产生额外历史步骤。
- [ ] 翻页验收样例在编辑模式不会因选中对象误翻页或切换主题，在预览模式恢复其原操作。
- [ ] 长滚动验收样例在预览模式恢复导航和锚点行为，返回编辑模式后可以继续选择当前可见对象。
