# 08 — 应用对象级局部外观覆盖

**What to build:** 用户可以通过对象属性区修改当前文字、图片或普通容器的背景、边框与圆角，而不会改写原始共享样式或连带改变其他同类对象；结果在编辑、历史、本地恢复和导出中保持一致。

**Blocked by:** 03 — 发现并层级选择可编辑对象.

**Status:** ready-for-agent

- [ ] 对象属性区根据当前对象类型显示适用的背景色、边框颜色、边框样式、边框宽度和圆角设置。
- [ ] 属性调整立即使用浏览器真实渲染更新工作副本，并使选框在尺寸变化时同步。
- [ ] 外观修改通过稳定编辑标识局部作用于当前选中对象，不直接改写原始共享 CSS 规则。
- [ ] 两个使用相同类名或选择器的对象中，只修改被选对象；未选对象保持原外观。
- [ ] 选择父容器时只修改容器本身，不隐式批量修改所有后代对象。
- [ ] 每次已提交的外观操作以用户意图进入历史，并支持撤销和重做。
- [ ] 外观覆盖可以在刷新后恢复，并在 HTML 交付文件中与导出前工作副本一致。
- [ ] 端到端回归覆盖共享类名对象，防止局部外观修改扩大为全局样式变化。
