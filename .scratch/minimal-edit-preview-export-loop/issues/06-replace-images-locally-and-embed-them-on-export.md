# 06 — 本地替换图片并在导出时内嵌

**What to build:** 用户可以确认当前选中的普通图片，从本地选择新图片进行替换，立即按照原对象规则看到真实结果，并让替换在撤销、重做、本地恢复和单文件 HTML 交付文件中保持一致。

**Blocked by:** 03 — 发现并层级选择可编辑对象.

**Status:** ready-for-agent

- [ ] 对象属性区仅在普通图片对象被选择时提供本地图片替换操作，并显示足以确认目标的图片信息。
- [ ] 选择本地图片后，工作副本立即显示替换结果，并沿用原图片对象的布局尺寸和首版基础外观规则。
- [ ] 替换只作用于当前选中图片，不改变共享相同类名或来源地址的其他图片。
- [ ] 一次替换形成一个用户意图级历史步骤，撤销恢复原图，重做恢复替换图。
- [ ] 替换图片数据保存在浏览器本地项目中，刷新恢复不依赖用户再次选择本地文件。
- [ ] HTML 交付文件内嵌替换图片，在离开 Web 编辑器且无法访问原本地图片路径时仍能显示。
- [ ] 图片选择取消、无法读取和不受支持图片数据会给出明确错误，并保持修改前状态。
- [ ] 端到端测试验证即时显示、局部作用、撤销、重做、刷新恢复和独立导出显示。
