# 07 — 视觉移动与等比缩放对象

**What to build:** 用户可以像使用演示文稿工具一样拖动文字、图片或普通容器并通过手柄等比改变显示尺寸；操作提供连续反馈，但不改变对象在原文档流、Flex 或 Grid 中的占位，也不覆盖原页面已有的变换。

**Blocked by:** 03 — 发现并层级选择可编辑对象; 04 — 支持参考视口与长页面浏览.

**Status:** resolved

- [x] 拖动当前可编辑对象时，选框和工作副本连续反馈视觉位移，松开后形成一个用户意图级历史步骤。
- [x] 角部手柄默认保持纵横比进行视觉缩放，操作过程中连续显示对象与选框的最终边界。
- [x] 视觉位移和视觉缩放不改变对象在原文档流、Flex 或 Grid 中的布局占位；相邻内容不会因拖动自动补位。
- [x] 操作造成的空白或重叠以真实渲染结果直接呈现，不由编辑器暗中重排页面。
- [x] 新增视觉变换与对象原有变换组合，不覆盖原 HTML 的 `transform` 或动画定义。
- [x] 变换只作用于当前选择；共享 CSS 类的其他对象以及未选择的后代对象不被连带修改。
- [x] 位移和缩放支持撤销、重做、浏览器本地恢复，并在 HTML 交付文件中与导出前工作副本一致。
- [x] 端到端测试以渲染边界和邻近内容的可见结果验证行为，不依赖内部 CSS 表达方式。

## Answer

在工作台选框上提供直接拖动与四角等比缩放手柄。视觉变换以稳定编辑标识生成局部修改层规则，并使用可组合的视觉属性保留原对象 `transform`；提交、历史、本地恢复和导出共用同一修改数据。真实 Chromium E2E 覆盖连续反馈、Flex 邻居占位、重叠、局部作用、原变换保留、撤销/重做、刷新恢复及独立导出渲染。
