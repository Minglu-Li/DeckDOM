# 13 — 用两份验收样例关闭 MVP 发布门槛

**What to build:** 使用现有翻页式和长滚动响应式验收样例，证明 MVP 已形成稳定的“导入—层级选择—直接编辑—撤销/重做—预览—本地恢复—导出”闭环，并为关键页面状态建立可持续的视觉与交互回归门槛。

**Blocked by:** 04 — 支持参考视口与长页面浏览; 09 — 隔离编辑操作并恢复预览行为; 11 — 统一全部修改的编辑历史与本地项目恢复; 12 — 固化高保真的 HTML 交付文件.

**Status:** ready-for-agent

- [ ] 两份验收样例均从未经预处理的原始 HTML 输入走完整端到端流程，不依赖测试专用标记或手工改造。
- [ ] 两份样例导入后保留主要布局、视觉内容和原文档形态，并能选择常见文字、图片、普通容器与父容器。
- [ ] 两份样例均验证文字编辑、图片替换、视觉位移、视觉缩放、字体和对象级外观修改的即时渲染。
- [ ] 两份样例均验证跨修改类型的撤销、重做、刷新恢复和最近项目恢复。
- [ ] 翻页样例验证编辑模式不会误触上一页、下一页、主题或页面快捷键，预览与导出后恢复原翻页和主题行为。
- [ ] 长滚动样例验证编辑模式可滚动到不同区块、参考视口触发原响应式规则，预览与导出后恢复导航和锚点行为。
- [ ] 两份样例导出的单文件 HTML 均能在不加载 Web 编辑器的独立页面环境打开并保留全部首版修改。
- [ ] 关键初始、编辑后、预览和导出状态具有区域级或页面级视觉回归基线，容差固定并允许可解释的浏览器字体渲染差异。
- [ ] 回归检查确认编辑器未引入结构重排、动画删除、原交互失效、未编辑对象样式变化或编辑辅助界面泄漏。
- [ ] 所有验收通过才视为 MVP 发布门槛关闭；结果不得被表述为支持所有 AI 生成 HTML。
