# 11 — 统一全部修改的编辑历史与本地项目恢复

**What to build:** 用户对文字、图片、视觉变换和外观做出的所有首版修改共享一套可预测的用户意图级编辑历史，并在浏览器刷新或重新打开后恢复最近项目；保存失败时产品明确告知，避免用户误以为工作已经安全保存。

**Blocked by:** 05 — 就地编辑文字并保留内联结构; 06 — 本地替换图片并在导出时内嵌; 07 — 视觉移动与等比缩放对象; 08 — 应用对象级局部外观覆盖.

**Status:** ready-for-agent

- [ ] 文字内容、字体属性、图片替换、视觉位移、视觉缩放和外观覆盖全部进入同一编辑历史。
- [ ] 历史按用户意图而非指针移动或输入事件数量分组，一次完整拖动、缩放或文字提交只需撤销一次。
- [ ] `Ctrl+Z` 撤销，`Ctrl+Y` 和 `Ctrl+Shift+Z` 重做；连续多步操作按照真实提交顺序往返。
- [ ] 撤销后产生新修改时，已失效的重做分支不再错误应用。
- [ ] 撤销和重做同步更新工作副本、当前选框、HTML 层级状态和对象属性区。
- [ ] 用户可以连续撤销回刚导入时的原始效果，而原始上传 HTML 始终保持不可变。
- [ ] 每次已提交操作后自动保存原始 HTML、修改层和编辑历史；刷新或重新打开浏览器后可从最近项目恢复。
- [ ] 本地保存失败、浏览器空间不足或项目数据无法恢复时显示明确且可操作的错误，不继续显示虚假的已保存状态。
- [ ] 自动化测试隔离各用例的浏览器存储，并覆盖跨不同操作类型的连续撤销、重做和刷新恢复。
