# 10 — 处理导入边界与资源诊断

**What to build:** 用户在导入前后能够理解 MVP 的输入、安全、本地处理和资源边界；不受支持或无法完整载入的输入产生明确、可恢复的诊断，而不是空白工作台、虚假成功或对任意 HTML 的兼容承诺。

**Blocked by:** 02 — 打通纯文字对象的最小完整闭环.

**Status:** ready-for-agent

- [ ] 文件选择只接受单个 HTML；非 HTML、ZIP、资源目录或源码工程会被明确拒绝并说明 MVP 支持范围。
- [ ] 导入前明确提示只打开受信任输入，并说明原 HTML 的脚本、外部资源、网络请求和交互会真实运行。
- [ ] 界面区分“用户文件不上传产品服务器”和“原页面可能访问第三方网络”，不宣称整个使用过程完全离线。
- [ ] 无法解析或无法载入的 HTML 显示可理解错误并允许重新选择文件，不覆盖最近可恢复的本地项目。
- [ ] 指向未提供本地相对路径的资源被识别并显示缺失状态，页面其余可运行内容仍尽量保留。
- [ ] 原文档已有的外部 URL 按原地址加载；加载失败时显示资源提示，但不擅自重写脚本或页面结构。
- [ ] 锁定内容、缺失资源、兼容性提示和导入错误在界面中是可区分的状态。
- [ ] 端到端测试覆盖非 HTML 拒绝、坏输入恢复、缺失相对资源、受信任输入确认和本地处理说明。
