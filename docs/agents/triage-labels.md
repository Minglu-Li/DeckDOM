# Triage Labels

The engineering skills use five canonical triage roles. This project keeps their default label strings unchanged.

| Canonical role | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting for more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an implementation agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or intervention |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a canonical role, use the corresponding label string from this table.
