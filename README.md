# DeckDOM

面向桌面 Chrome 和 Edge 的本地优先 HTML 展示文档编辑器。

## 本地开发

准备 Node.js `^20.19.0` 或 `>=22.12.0`，安装依赖后，使用仓库的单一开发命令启动应用：

```powershell
npm install
```

```powershell
npm run dev
```

Vite 会输出本地访问地址。用户文档后续由浏览器本地处理；开发服务器只分发编辑器自身的静态资源。本地处理不等于完全离线：原 HTML 中的外部图片、样式、字体和脚本链接会继续保留，预览或导出的文件仍可能访问网络；MVP 不会自动把这些外部依赖打包进单文件。

编辑能力面向最新版桌面 Chrome 和 Edge。自动化发布门槛在最新版桌面 Chrome 上运行；Edge 的产品承诺基于共同的 Chromium 平台和人工兼容检查，不等同于每次发布均执行独立 Edge 自动化套件。移动浏览器、旧版浏览器和非 Chromium 浏览器不在首版承诺内。

打开应用后，确认受信任输入提示并选择一个本地 `.html` 文件。当前最小闭环支持在工作副本中选择文字对象，双击后在真实渲染位置编辑并保留已有内联结构；外部粘贴按纯文本处理。对象属性区可显式替换全部文字（含清除内联格式确认），并调整整个文字对象的字体族、字号、字重、字形、行高、字间距、对齐和文字颜色。文字、图片和普通容器还可以独立覆盖背景色、边框颜色、边框样式、边框宽度与圆角；这些外观覆盖只作用于当前对象，不会改写共享 CSS 或批量修改后代。内容、字体与外观修改均支持撤销、重做、刷新恢复、预览和独立 HTML 导出，原始本地文件不会被编辑器覆盖。

导入后，编辑器会在运行时识别文字对象、图片和普通容器，并在左侧 HTML 层级树中显示可编辑、整体对象或锁定状态。可以直接单击工作副本中的内容、搜索层级树，或从当前对象向上选择父容器；对象路径、层级树、属性区与选框会保持同步。选中外层容器后，蓝框内部仍可直接点击子对象；拖动对象需抓住蓝色对象标签，四角只负责等比缩放。点击画布空白或按 `Esc` 可取消选择。复杂内容保持原样运行，不开放不可靠的内部编辑。

编辑模式默认使用“选择内容”工具，原 HTML 的按钮、链接和页面快捷键不会误触。需要在 `test1.html` 一类翻页文档中切页、切主题或操作原组件时，可切换到“操作页面”；它会把点击与键盘连续交还原 HTML，但保持在同一工作副本和编辑模式中。按 `Esc` 返回“选择内容”，页面状态不会重载，工具切换也不会进入撤销历史。

替换图片时会先验证本地文件，再显示适配方式。默认“直接替换”保留新图片自身比例并继续遵循原页面 CSS；“填充原图框”记录当前参考视口下原图片的渲染宽高，以居中 `object-fit: cover` 填满该框。后者只隐藏框外内容，不裁掉或改写图片像素，也不是自由裁剪编辑器；图片内容与适配方式作为一次操作共同支持撤销、恢复和导出。

工作副本默认使用 1440×900 参考视口。工具栏可以应用其他桌面宽高，让原 HTML 的响应式 CSS 按真实 iframe 视口重新布局；放大、缩小和“适合画布”只改变工作台中的显示比例，不改变文档布局尺寸。长页面继续在工作副本中滚动，翻页式文档也继续保留自身的翻页形态。修改结果只保证当前参考视口下的预期表现。

选中文字、图片或普通容器后，可以拖动蓝色对象标签做视觉位移，也可以拖动四角手柄等比视觉缩放。操作不会改变对象在原文档流、Flex 或 Grid 中的占位，因此真实空白或重叠会直接保留；对象原有的变换仍与修改层组合生效。一次完整拖动形成一个可撤销、重做和自动保存的历史步骤。

文字、字体、图片、视觉位移、视觉缩放与外观修改共享一套用户意图级历史；可使用工具栏或 `Ctrl+Z` 撤销，并用 `Ctrl+Y` / `Ctrl+Shift+Z` 重做。每次提交后，原始 HTML、修改层和历史会自动保存在浏览器中，刷新或重新打开页面可恢复最近项目。若浏览器空间不足或本地保存失败，界面会明确标记修改尚未安全保存并提示立即导出 HTML；损坏的最近项目也会提供清除数据并重新选择 HTML 的恢复入口。

## 验证

```powershell
npm run build
npm run test:e2e
```

端到端测试使用真实桌面 Chrome，并直接载入 `testexample/test1.html` 与 `testexample/test2.html` 两份未经预处理的验收样例。它们分别证明翻页式文档和长滚动响应式文档的首版闭环，但不代表编辑器支持所有 AI 生成 HTML；新的文档形态仍需新增明确的验收证据。后续垂直切片继续沿用这一最高层测试入口。
